# Exclusive

대한민국 주요 26개 언론사(종합지·경제지·IT 및 반도체 전문지)에서 발행되는 기업·자본시장 관련 `[단독]` 기사를 24시간 감시하여 텔레그램 채널(`@chartbooknews`)로 전송하는 자동화 봇입니다.

## 주요 기능
- 26개 매체 공식 RSS 및 구글 뉴스 전용 RSS 병렬 수집 (별도 뉴스 API 키 불필요)
- 6대 기업·자본시장 이벤트 키워드 필터링 및 스포츠·사회 노이즈 제외 필터
- 링크 및 유사 제목 기반 중복 발송 방지 (`sent_history.json` 자동 백업)
- GitHub Actions 5분 주기 무중단 24시간 실행

## 환경 변수 (GitHub Secrets)
- `TELEGRAM_BOT_TOKEN`: 텔레그램 봇 토큰 (채널 관리자 권한 필요)
